# Browser verification scope

The cloud browser preview runtime was unavailable during this release. Browser visual/interaction QA was not completed and is not represented as passed.

Node tests exercise the actual report parser, project/schema isolation, duplicate keys, UTF-8 byte/depth/node bounds, numeric precision, prototype keys, fixture import and restrictive asset/rendering rules. CLI and upstream engine verification are recorded separately in reports/validation.json and upstream smoke reports.

Serve web/ using the command in WEB_VIEWER.md to review the responsive layout. docs/cover.svg is an original illustration, not a screenshot or evidence of browser testing.
